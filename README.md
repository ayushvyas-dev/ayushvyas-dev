## 🚀 Projects

### 🔐 Team Access Control

> A production-style full-stack application for managing organizations, teams, memberships and permissions.

Built with a strong focus on **backend architecture, authentication, authorization, security and scalable system design**.

* 🔑 JWT authentication with access & refresh tokens
* 🔄 Refresh-token rotation and server-side session management
* 🏢 Multi-organization architecture with organization memberships
* 🛡️ Role-Based Access Control with permission-based authorization
* ✉️ Organization invitations with expiry and status tracking
* 📝 Transactional audit logging for important organization actions
* ⚡ Redis-backed rate limiting
* 📬 BullMQ background jobs for asynchronous email delivery
* 🗄️ PostgreSQL with Prisma ORM and database migrations
* 📚 OpenAPI / Swagger API documentation
* 🧪 Unit & integration testing

**Stack:** Node.js · TypeScript · Express · PostgreSQL · Prisma · Redis · BullMQ · JWT · Zod · Next.js
